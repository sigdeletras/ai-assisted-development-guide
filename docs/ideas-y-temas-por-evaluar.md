# Banco de ideas

Ideas para evaluar antes de incorporarlas al temario. No son contenidos aprobados.

## Ideas pendientes

### 1. Un proyecto común para los laboratorios

- **Propuesta:** usar una API REST en Python como proyecto transversal; replicable después en otros lenguajes.
- **Ventaja esperada:** aprender distintas prácticas de IA sobre el mismo código base.
- **Por decidir:** alcance de la API, evolución entre laboratorios y estrategia para mantener versiones reproducibles.
- **Estado:** pendiente de evaluación.

### 2. Chuleta de comandos de Claude Code CLI

- **Propuesta:** referencia breve organizada por tareas: inicialización, sesiones, contexto y permisos.
- **Ejemplo:** `/init` analiza el proyecto y genera una primera versión de `CLAUDE.md`; debe revisarse antes de adoptarla.
- **Por decidir:** guía específica de Claude Code o comparativa con otras herramientas. Evitar falsas equivalencias y advertir que los comandos varían según la versión y configuración.
- **Fuentes oficiales:** [CLI reference](https://docs.anthropic.com/en/docs/claude-code/cli-usage) · [Cheatsheet](https://support.claude.com/en/articles/14553413-claude-code-cheatsheet)
- **Estado:** pendiente de evaluación.

## Criterios de evaluación

- Utilidad y encaje en el itinerario.
- Ausencia de duplicidades.
- Verificabilidad y calidad de las fuentes.
- Enfoque agnóstico y diferencias entre proveedores.
- Coste de mantenimiento proporcional al valor.
