# AI-Assisted Development Guide

Guía práctica para integrar asistentes y agentes de IA en el desarrollo de software con revisión humana, verificación y seguridad.

## Empieza aquí

1. Lee los [primeros pasos](docs/primeros-pasos.md).
2. Realiza el [laboratorio 01: primer contacto](laboratorio/01-primer-contacto/README.md).

- **[Empezar a programar con IA](docs/primeros-pasos.md)** — completa una primera tarea y aprende a verificar el resultado.
- **[Consultar el glosario](docs/glosario.md)** — encuentra definiciones breves de los conceptos y términos técnicos.
- **[Practicar con un proyecto](laboratorio/README.md)** — aplica el método con ejercicios progresivos.
- **[Explorar herramientas de desarrollo con IA](docs/herramientas-desarrollo-ia.md)** — compara rápidamente categorías y ejemplos representativos.
- **[Consultar documentación de herramientas](docs/referencias-herramientas.md)** — accede a referencias oficiales de configuración y uso.
- **[Profundizar en un tema](docs/mapa-contenidos.md)** — encuentra conceptos, criterios y metodologías por módulo.
