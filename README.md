# AI-Assisted Development Guide

Guía práctica para integrar asistentes y agentes de IA en el desarrollo de software con revisión humana, verificación y seguridad.

## Empieza aquí

1. **[Empezar a programar con IA](docs/primeros-pasos.md)** — completa una primera tarea y aprende a verificar el resultado.
2. **[Consultar el glosario](docs/glosario.md)** — encuentra definiciones breves de los conceptos y términos técnicos.
3. **[Practicar con un proyecto](laboratorio/README.md)** — aplica el método con ejercicios progresivos.
4. **[Explorar herramientas de desarrollo con IA](docs/herramientas-desarrollo-ia.md)** — compara rápidamente categorías y ejemplos representativos.
5. **[Consultar documentación de herramientas](docs/referencias-herramientas.md)** — accede a referencias oficiales de configuración y uso.
5. **[Profundizar en un tema](docs/mapa-contenidos.md)** — encuentra conceptos, criterios y metodologías por módulo.

## Consulta la guía

- [Mapa de contenidos](docs/mapa-contenidos.md): conceptos, metodologías y criterios de decisión.
- [Referencias de herramientas](docs/referencias-herramientas.md): documentación oficial, inicios rápidos y equivalencias.
- [Laboratorios](laboratorio/README.md): ejercicios prácticos.
- [Roadmap](ROADMAP.md): mejoras y contenidos pendientes.
