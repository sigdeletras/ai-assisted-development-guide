# AI-Assisted Development Guide

Guía práctica para integrar asistentes y agentes de IA en el desarrollo de software con revisión humana, verificación y seguridad.

## Empieza aquí

1. **[Empezar a programar con IA](docs/primeros-pasos.md)** — completa una primera tarea y aprende a verificar el resultado.
2. **[Consultar el glosario](docs/glosario.md)** — encuentra definiciones breves de los conceptos y términos técnicos.
3. **[Practicar con un proyecto](laboratorio/README.md)** — aplica el método con ejercicios progresivos.
