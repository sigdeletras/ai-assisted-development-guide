# AI-Assisted Development Guide

Guía práctica para trabajar con asistentes y agentes de IA con calidad, seguridad y revisión humana.

**Empieza con una tarea pequeña. No necesitas configurar todas las capacidades de IA para obtener resultados útiles.**

## ¿Qué necesitas hacer?

- **[Empezar a programar con IA](docs/primeros-pasos.md)** — completa una primera tarea y aprende a verificar el resultado.
- **[Practicar con un proyecto](laboratorio/README.md)** — aplica el método con ejercicios progresivos.
- **[Configurar una herramienta](docs/referencias-herramientas.md)** — consulta los puntos de entrada oficiales de Copilot, Claude Code, Cursor y Codex.
- **[Profundizar en un tema](docs/mapa-contenidos.md)** — encuentra conceptos, criterios y metodologías por módulo.

## El método básico

1. Define una tarea concreta y cómo comprobar que está resuelta.
2. Aporta solo el contexto necesario y autorizado.
3. Pide una explicación o un plan antes de cambios complejos.
4. Revisa el diff y ejecuta las pruebas.
5. Acepta únicamente los cambios que entiendas y hayas verificado.

No empieces configurando agentes, skills, hooks o MCP salvo que resuelvan una necesidad concreta.

## Principios

- Priorizar documentación oficial y fuentes verificables.
- Explicar primero los principios comunes y después las diferencias entre proveedores.
- Proteger credenciales, datos de clientes y código confidencial.
- Mantener la revisión humana y la verificación como parte del flujo.
